# Student Innovation Hub

A dark, animated multi-page website built with plain HTML, CSS and JavaScript. It does not need Python, Flask, an install step or a running server.

## Open the site

Double-click `index.html` to open the home page in a modern browser. Use the navigation to open Projects, Team and Contact. Project cards open their own detail pages.

## Files

- `index.html` - home page and featured project/team previews
- `projects.html` - project search and category filters
- `project.html` - project detail page
- `team.html` - hub coordinators and mentors
- `contact.html` - contact form
- `style.css` - layout, colors, illustrations and animations
- `web.js` - project/team content and page interactions

The contact form saves messages in this browser's local storage. It does not email or send them to another person. Project and team names are sample content near the top of `web.js` and can be edited there.
